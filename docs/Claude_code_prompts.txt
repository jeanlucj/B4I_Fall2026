[2026-09-20 17:53:30] Now, I want to try to use the extended MegaLMM framework to analyze this oat-pea experiment.  The idea follows.  Starting from the point of view of the oat, consider each pea accession as a different "environment" for the oats.  Thus, if we have 400 different pea accessions, we have 400 different environments.  Say we also have 500 oat accessions.  In the MegaLMM framework, this defines a 500 x 400 matrix which is very sparsely populated.  It's an empirical question as to whether the MegaLMM analysis can overcome that degree of sparsity and give meaningful results, but I want to try.  A first question is what values, exactly, to put in the sparse matrix.  We have oat x pea combinations from different trials.  I can think of three possibilities, maybe you can think of others. 1. Just take the raw oat yield from each oat x pea combination and put that value in the corresponding oat accession x pea environment cell of the matrix. 2. Before putting values in the matrix, center within each trial by subtracting the mean oat yield from each raw oat yield.  Put the centered oat yield in the corresponding oat accession x pea environment cell of the matrix.  3. Before putting values in the matrix, standardize within each trial, subtracting the mean and dividing by the standard deviation of oat yield.  In principle, MegaLMM works better if we can provide meaningful environmental covariates.  Here, those covariates should characterize the pea accession.  First, I would use the pea yield BLUE across the full experiment as a characteristic of the pea.  I would also use pea flowering date or pea maturity date.  I suspect they are too strongly correlated for it to make sense to use both.  Then, because we have DNA markers for the peas, we can include eigenvectors from the pea GRM as pea characteristics.  I have no idea how many to include.  Maybe start by including enough to cover 80% of the pea genetic variance.  An example of the use of the MegaLMM model is in the sibling repo BarleyWinterSurvival.  An example of extended MegaLMM using environmental covariates is in the sibling repo DSFASrecommending.
